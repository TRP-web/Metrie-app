# Installation

The easiest way to run the app.

1. Instal [Node.js](https://nodejs.org/en/download/prebuilt-installer)
2. Download ZIP or clone this git project.
3. Use any terminal to open the directory metrie/front-end and run:
```bash
npm run dev
```
4. Use any new terminal to open the directory metrie/back-end and run:
```bash
node index.js
```
5.Open your browser on [localhost:3000](http://localhost:3000)
